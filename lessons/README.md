# Lessons Learned

Reviewed, generalised solutions to recurring development problems (testing strategies,
cross-platform pitfalls, build validation, packaging mistakes, dependency management,
security and Git workflow improvements, reproducibility).

Each lesson is one Markdown file with this header:

```text
---
promoted: YYYY-MM-DD
reviewed: yes
origin: <generic description, no private identifiers>
---
```

Requirements for every lesson:

- Verified and technically correct; describes the problem, the cause and the solution.
- Generalised: no project names that are not public, no source code that is not public,
  no personal data, credentials, internal hosts, paths or confidential context.
- Not a duplicate of existing guidance; if it refines a policy, update that policy
  instead and keep the lesson short or remove it.

Lessons are added only after review and with the maintainer's explicit approval.
