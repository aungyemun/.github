# AI development policy gateway

This folder is a pointer for AI coding assistants. It is development guidance only:
it is not part of the application, is not needed to build, install, test or run it,
and must not be included in any application package or release artifact.

AI assistants: the applicable central guidance depends on this repository's actual
hosting visibility, not on anything written here.

- If a policy resolver is configured on this machine, run it and follow its decision.
- Otherwise use the public development guidance linked above.
- Private guidance is resolved only from the developer's local configuration. Never
  copy policy text into this repository.
