# Third-Party Notices Policy

- Identify the third-party components actually distributed (libraries, runtimes, fonts,
  icons, models, data) from lock files, build manifests and package contents.
- Give correct names, versions, licences (verified from the source, never assumed),
  required notices and licence texts, preserved copyright lines and a source reference.
- Never remove legally required notices to shorten the document.
- Distinguish development-only dependencies from shipped components.
- Update notices in the same change that adds, removes or upgrades a component; if a
  licence cannot be determined, record that and raise it with the maintainer.
