# Privacy Documentation Policy

Describe actual behaviour, established by examining code, configuration and dependencies:
data collected; local storage locations and retention; every kind of network communication
(update checks, licence checks, online features, embedded web content, remote fonts);
telemetry and crash reporting; third-party services; transmission security where verified;
user controls.

Do not claim that software is fully offline or collects no data unless that was checked;
"core features work locally" is not the same as "no network access". Avoid legal compliance
claims unless the maintainer has established them.
