# Licence Documentation Policy

Licence documents are legally sensitive.

- Identify the licence actually chosen (licence file, package metadata, file headers) and
  report inconsistencies rather than silently changing them.
- Keep the official text of standard licences (MIT, BSD, Apache-2.0, GPL, LGPL, AGPL, MPL,
  CC) verbatim; never reword it to sound more professional.
- Preserve copyright notices and attribution obligations exactly.
- Never invent permissions, restrictions, exceptions or warranties.
- Keep the project's own licence distinct from third-party licences.
- Check compatibility before recommending a different licence, and note that this is not
  legal advice.
- Changing, replacing or removing a licence, or editing licence text or copyright lines,
  requires the maintainer's explicit decision.
